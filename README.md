# Transcriber

The app page for the Roos family transcriber, served at https://transcriber.roosfamily.com.

This repo is only the screen. Recordings, transcripts and summaries live on the home NAS and are
reachable only from devices signed in to the family Tailscale network; the page calls the NAS
at `https://transcriber.tail71c8a7.ts.net/`, which only accepts requests from this site.
